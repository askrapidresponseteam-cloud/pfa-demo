# Public Copy Audit

This pass separates public website content from internal product, UX and implementation instructions.

## Removed from public pages

- Internal guidance about reducing clicks
- Claims about page architecture or interface design
- Prototype, static build and placeholder wording
- API, webhook, supplier and logistics implementation language
- Notes written to the designer or developer
- Explanations of why a control or page was designed a certain way

## Replaced with

- Animal welfare information
- Product and service information
- Clear customer actions
- Public policies and terms
- Direct instructions needed to complete a real user task

## Verification

- 35 HTML pages audited
- 26 JavaScript files audited
- All internal links and fragments resolve
- All JavaScript files pass syntax validation
- No forbidden internal instruction phrases remain in public page copy
- No em dash or en dash characters remain
