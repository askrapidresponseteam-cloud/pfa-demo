# Photographs of the unit in-charges

Drop a portrait here as `<city-slug>.webp` (lower-case, hyphens: `calicut.webp`,
`charkhi-dadri.webp`) and units.html shows it in that unit's profile with no
code change. Until a file exists, the page renders a typographic plate instead;
nothing ever shows a broken frame or the wrong face. Portrait crops around 3:4
and at least 700px wide read best.
